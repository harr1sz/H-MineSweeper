# Contributing

H-MineSweeper is open source under the [MIT License](./LICENSE). Issue reports
and scoped contribution proposals are welcome.

- Bug reports and scoped research feedback are welcome through the repository
  issue forms.
- Scoped external pull requests may be proposed and are reviewed at the
  maintainer's discretion; submission does not imply acceptance.
- Do not submit secrets, private room data, tokens, personal data, full IP
  addresses, board seeds, or raw telemetry.
- Each implementation pull request should close one child issue and follow the
  repository pull request template.
- Passing CI is necessary but does not prove product validation, release
  readiness, or completion of Phase 1.

Security concerns must follow [SECURITY.md](./SECURITY.md), not a public issue.
